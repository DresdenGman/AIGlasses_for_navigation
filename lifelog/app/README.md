# Lifelog — AI Glasses companion app

One codebase, five platforms: **iOS · Android · macOS · Windows · Linux**.
Tauri 2 native shell + React + Vite + TypeScript front-end.

> **Front-end demo (v0.1.1; first released as v0.1.0).** Every screen is fully interactive, but capture,
> sync and inference are simulated: the app ships with the same **fictional
> showcase data** as the website (sample day 2026-04-18), clearly labelled
> "Demo data" in the UI. The real pipeline (glasses frame capture, watch
> audio ingest, NAS/cloud backup, on-device inference) plugs into the Tauri
> shell later, behind the entry point in `src-tauri/src/lib.rs`.
> Research prototype — **not a medical device**; it does not replace a white
> cane, a guide dog, or orientation-and-mobility training.

## Screens

| Page | What it does |
|---|---|
| **Today** | Recording status (glasses capturing / watch recording / sync), one-tap pause & resume, day stats, device list |
| **Timeline** | Hour-by-hour replay of the sample day: filmstrip + segment cards, tap for segment detail |
| **Summary** | AI daily summary in four parts (went / did / met / said) + year-in-numbers |
| **Ask** | Ask-your-day search over 46 preset Q&A per language (EN / 中文）; answers carry evidence timestamp chips that jump to the segment; uncertain answers get the amber dashed treatment; no evidence → it says "not in records" |
| **Objects** | Tracked items with last confirmed sighting (time, place, the frame itself, bounding outline); later shaky sightings labelled *uncertain* |
| **Guide** | The glasses' own live scene narration, simulated from the sample day's captions; below the confidence threshold it announces "Uncertain: …" instead of guessing |
| **Backup** | Cloud vs home-NAS target cards, storage meter, recent backup runs |
| **Privacy** | Pause switch, local-first switch, auto-delete retention (30/90/180/365 days), full egress log, permanent-delete flow with audit history |
| **Settings** | Language （中文/EN), theme (light / dark / system), confidence threshold slider (default **0.70**, matching the glasses), prototype statement |

Design language is shared with the website (`lifelog/web/design-tokens.json`):
museum-archive style — Inter + Newsreader + JetBrains Mono, paper/ink palette,
amber dashed = *uncertain*. Mobile-first layout: bottom tab bar on small
screens, left rail on desktop.

## Develop

```bash
npm install
npm run dev        # front-end only, http://localhost:5273
npm run build      # typecheck (tsc) + production build into dist/
npm run tauri dev  # native shell (needs the Rust toolchain, see below)
```

Demo data is generated from the website's showcase data — do not edit
`src/data/demo.json` by hand:

```bash
python3 tools/build_demo_data.py   # re-extracts + copies photos
```

## Build per platform

Prerequisites for native builds: Rust stable (`rustup`), plus per-OS deps
listed by the Tauri 2 prerequisites guide. CI (`.github/workflows/lifelog-app.yml`)
runs the full matrix on every push that touches `lifelog/app/**`.

| Platform | Command | Output |
|---|---|---|
| Windows | `npm run tauri build` | NSIS installer + MSI (`bundle.targets` in `src-tauri/tauri.conf.json`) |
| macOS | `npm run tauri build -- --target universal-apple-darwin` | .app + DMG (universal) |
| Linux | `npm run tauri build` | AppImage + .deb (+ .rpm) |
| Android | `npm run tauri android init` once, then `npm run tauri android build --apk` | APK (needs Android SDK/NDK + JDK 17) |
| iOS | `npm run tauri ios init` once, then `npm run tauri ios build` | .ipa — **requires an Apple Developer account**: set the development team in `src-tauri/tauri.conf.json` (`bundle.iOS.developmentTeam`) and provide signing certificate + provisioning profile. The CI iOS job performs an unsigned compile check only until those secrets exist. |
