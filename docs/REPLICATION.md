# Independent build replication

Everything else in this repository is published by the project itself. This page exists so that someone else can check the most important claim in it — that the glasses can be built from the public documentation — and leave a public record of what happened.

## What counts as a replication

- You build from the **public documentation only**: the [bill of materials](BOM_BILINGUAL.md), the assembly card, the design files and the demo software in this repository. Questions that the documentation cannot answer are themselves a result — write them down instead of asking privately.
- You keep a log (template below) and share it, whatever the outcome. **A replication that fails is still evidence** — it shows exactly where the documentation or the design stops working for a second builder.
- Photos of the finished (or furthest-progressed) build are welcome but optional. Do not include identifiable people without their consent.

## Log template

Copy this into the [replication issue](../../issues) or a pull request adding your log under `docs/replications/`:

```markdown
## Replication log

- Builder (name or handle):
- Date started / finished:
- Documentation version used (release tag or commit):
- Parts sourced from (supplier, total hardware cost, currency):
- Assembly time (roughly, in hours):
- Steps where the documentation was unclear or wrong:
- Deviations from the documentation (and why):
- Did the guidance demo run? (yes / no / partly — what happened)
- Did the camera path run? (yes / no / partly)
- Anything that did not fit, broke, or had to be reprinted:
- Overall: could someone else repeat your build from the docs plus this log? (yes / with effort / no)
```
