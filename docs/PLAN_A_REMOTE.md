# 方案 A：远程视频连线主持（一页纸）

> 状态：待用户拍板。证据强度：强。

## 流程

1. 用户通过视频连线（腾讯会议/Zoom）远程主持 60–90 分钟教学跟进：先请老人回忆上次内容，再解决 1–2 个实际卡点。
2. 居委会对接人负责现场：约老人、准备场地和大屏/音响、签到、发问卷。
3. 1–2 周后用户再远程回访 30 分钟：请老人独立复述 2–3 个关键步骤（记录：能独立完成 / 需提示 / 不能完成），回收问卷。

## 谁做什么

| 角色 | 负责 |
|---|---|
| 用户 | 准备讲义、主持连线、做记录、远程回访、整理证据 |
| 居委会对接人 | 约老人、场地、大屏+音响、现场签到、协助问卷发放回收 |
| 本地志愿者（可选） | 现场协助老人操作设备 |

## 时间线

- 9/28 前：定社区、对接人，加微信，寄工具包
- 10/5 前：工具包寄达，测试连线（网络+音响）
- 10/12–10/16：教学跟进（60–90 分钟）
- 10/20–10/26：远程回访（30 分钟）
- 10/31 前：脱敏证据成稿

## 需要的材料

- 工具包打印版（BOM 双语清单、组装步骤卡、故障一页纸）× 应邀人数 + 2 备用
- 问卷纸质版 × 应邀人数 + 5 备用、签到表、笔
- 现场：大屏/投影 + 音响（必须够大声）、稳定的网络

## 风险 / 注意事项

- 网络不稳定 → 提前一天实测；准备电话备用方案。
- 老人听不清远程声音 → 现场音响是关键，提前试音；语速放慢一半。
- 对接人配合度决定成败 → 提前一周确认，活动前一天再提醒。
- **诚实备注**：单社区完全符合条件的老人不多、有人会拒绝参加——应邀/实到人数照实记录，不美化。

## 用户时间投入：约 5–7 小时
