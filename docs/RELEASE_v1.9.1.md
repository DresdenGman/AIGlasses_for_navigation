# Project release v1.9.1

A patch release over [v1.9](RELEASE_v1.9.md) with no code changes.

- The front page now carries a **recorded run of the included demo** (`assets/demo.gif`): the dashboard's four sample observations passing through the real guidance engine, ending with the low-confidence case answered as uncertainty rather than a command.
- **Zenodo archiving is enabled for this repository** from this release onward, so the release is preserved under a DOI. (Zenodo only archives releases published after its GitHub switch is turned on; v1.8 and v1.9 predate the switch and have no DOI.)

Everything else — package 0.1.0, design v0.4, the evaluation, the priced build and the protocols — is exactly as in v1.9.

**Archive:** this release is preserved on Zenodo — version DOI [10.5281/zenodo.23977545](https://doi.org/10.5281/zenodo.23977545); cite all versions with the concept DOI [10.5281/zenodo.23977544](https://doi.org/10.5281/zenodo.23977544).
