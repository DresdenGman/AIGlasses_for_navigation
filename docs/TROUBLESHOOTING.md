# 常见故障一页纸 | Troubleshooting (One Pager)

> 先看这里，80% 的问题 5 分钟内能定位。修不好 → 去仓库提 issue，附上现象 + 已试过的步骤。

| 现象 Symptom | 可能原因 Likely cause | 排查步骤 Steps |
|---|---|---|
| 通电完全没反应 | 电池没电 / 极性接反 / 接触不良 | 1. 万用表测电池电压 2. 检查极性 3. 重新插拔接头 |
| 摄像头无画面 | 排线松动或插反 / 模组损坏 / 软件未识别到设备 | 1. 断电重插排线（注意方向） 2. 换 USB 口 / 线 3. 看软件日志有无设备枚举 |
| 有画面但无播报 | 音频输出没接好 / 音量为零 / 置信度阈值过高 | 1. 检查扬声器接线 2. 确认音量 3. 检查阈值是否为默认 0.70 |
| 播报不停 / 频繁误报 | 阈值过低 / 3 秒消息抑制未生效 / 环境光线剧烈变化 | 1. 恢复默认阈值 0.70 2. 确认软件版本包含消息抑制 3. 换稳定光线环境复测 |
| **低置信度时仍给方向指令** | **软件版本过旧，不含 Safety Note 行为** | **立即停用，升级到包含《低置信度行为准则》的版本后再用** |
| 佩戴压鼻梁 / 不适 | 鼻托未调整 / 尺寸不合 | 1. 调整鼻托角度 2. 检查上盖是否压迫 |
| 上下壳合不上 | 打印收缩 / 毛刺未清 / 方向装反 | 1. 清毛刺 2. 检查打印尺寸 3. 不要硬掰 |
| 续航明显偏短 | 电池老化 / 后台进程耗电 | 1. 充满后计时实测 2. 关闭不需要的进程 |

**修好后请做**：在回访记录里记一笔"什么故障、怎么修好的"——这是"可维护性"证据，申请材料里能用。
