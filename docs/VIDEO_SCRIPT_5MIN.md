# 5 分钟教学视频脚本 | 5-Minute Build Video Script

> 目标观众：零基础社区老人 / 家属 / 志愿者。语速放慢，关键步骤给特写 + 字幕。
> 画质要求不高，手机拍摄即可；必须配字幕。

## 0:00–0:30｜开场

- **画面**：讲者出镜，手持组装好的眼镜。
- **旁白**："大家好，我是 Dresden。这是一副帮助视障人士的 AI 眼镜，硬件成本不到 30 美元，设计和代码全部开源，**你自己也能做出来**。接下来 5 分钟，我带你从零把它组装好。"
- **字幕条**：开源地址（GitHub 仓库链接）。

## 0:30–1:15｜物料展示

- **画面**：按 BOM 表把物料一样样摆在桌上，镜头逐个扫过。
- **旁白**："先点料。对照物料清单：摄像头、主控板、电池、扬声器，还有 3D 打印的下壳和上盖。一样样数齐再动手，装到一半缺件最耽误事。"
- **备注**：BOM 表打印出来放在画面角落。

## 1:15–3:15｜组装演示（加速 + 关键处暂停）

- **画面**：组装过程 2 倍速播放，到下面三处**暂停 + 特写 + 字幕强调**：
  1. 摄像头对准开口（"镜头歪了，后面识别全偏"）；
  2. **电池最后接、注意极性**（"极性接反会烧板子，这一步最重要"）；
  3. 上电自检三步（晃手测试播报 → 遮挡镜头 → 确认只说"我不确定"不给方向）。
- **旁白**：按《组装步骤卡》Step 2–6 逐句讲解，每句不超过 15 个字。

## 3:15–4:15｜开机演示：三条真实规则

- **画面**：第一视角 + 设备播报声音实录。
- **旁白**："它会三件事：红灯说等待；近距离有障碍会提醒；**拿不准的时候，它只会说'我不确定'，绝不瞎指挥**。这条是它的铁律。"

## 4:15–4:45｜安全声明（必须保留，不许剪掉）

- **画面**：讲者正对镜头，语气放稳。
- **旁白**："重要的话说三遍：它是辅助工具，**不能替代盲杖和导盲犬**；不能帮你做过马路的决定；它不录像、不存你的任何信息。研究原型，安全第一。"

## 4:45–5:00｜结尾

- **画面**：开源仓库页面 + 社区活动照片。
- **旁白**："设计文件、代码、今天用的所有清单都在开源仓库里，免费。你做出来了、修好了，欢迎回来告诉我。谢谢大家。"
- **字幕条**：仓库链接 + 反馈渠道。
