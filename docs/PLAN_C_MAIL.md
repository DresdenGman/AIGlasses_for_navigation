# 方案 C：工具包寄送 + 远程回访（一页纸）

> 状态：待用户拍板。证据强度：弱（只有回访记录，无新教学）。最轻量保底方案。

## 流程

1. 不做新的教学活动。把工具包打印版 + 一封信寄给居委会对接人，请其转交给上次参加过的老人。
2. 信里说明：2 周后 Dresden 会逐个/集中电话或视频回访（30 分钟），请老人先看看材料。
3. 用户远程回访：请老人独立复述 2–3 个关键步骤（记录：能独立完成 / 需提示 / 不能完成）；问卷可电话代填。

## 谁做什么

| 角色 | 负责 |
|---|---|
| 用户 | 寄工具包、写信、逐个远程回访、整理证据 |
| 居委会对接人 | 转交材料、协助约回访时间 |
| 老人 | 自学材料、接回访电话 |

## 时间线

- 9/28 前：定社区、对接人，加微信
- 10/5 前：工具包寄出（顺丰，单号发对接人）
- 10/12–10/26：远程回访（分批电话，每人 15–30 分钟）
- 10/31 前：脱敏证据成稿

## 需要的材料

- 工具包打印版 × 上次参加人数 + 2 备用
- 给老人的信（一页纸：说明来意 + 回访时间 + "看不懂没关系，电话里我教"）
- 问卷纸质版（附回邮信封，或电话代填——建议电话代填为主）
- 给对接人的信（一页纸：麻烦转交 + 回访时间安排）

## 风险 / 注意事项

- 无现场教学，老人自学效果弱 → "能独立复述"人数可能很少。**照实记，不丢人**——诚实本身就是这个项目的差异化。
- 问卷回收率会低 → 以电话代填为主，不要干等回邮。
- 证据强度最弱：申请材料里只能写"回访 X 人"，没有新教学记录。建议作为保底：A/B 实在排不开时用。
- **诚实备注**：单社区完全符合条件的老人不多、有人会拒绝参加——应邀/实到人数照实记录，不美化。

## 用户时间投入：约 3–4 小时
