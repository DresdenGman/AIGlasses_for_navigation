# 低置信度行为准则 | Low-Confidence Behavior Code

**AI Glasses for Navigation — Safety Note v0.1**
日期 Date: 2026-09-25 ｜ 状态：草稿，欢迎社区反馈后修订

## 一句话原则

**当眼镜不确定时，它必须承认"我不知道"，绝不编造指令。**
*When uncertain, the glasses must say "I don't know" — never invent instructions.*

## 五条准则

### 准则 1：低置信度 = 只报不确定，不给行动指令
- 任何观察的置信度低于 **0.70**（默认值）时，设备只输出不确定性提示，并明确标记为**不可执行（non-actionable）**。
- 禁止行为：不得输出"向左走 / 向右走 / 往前走"等方向性指令。

### 准则 2：信号灯状态未知 = 不做"可以走"的暗示
- 红灯 → "红灯，请等待"，并提醒注意周围车辆。
- 绿灯 → 可以提示，但必须附加"请自行确认周围车辆"。
- 未知 → 只说"信号灯状态未知"，绝不暗示可以通过。

### 准则 3：距离 / 障碍物不确定 = 只提醒注意，不指挥避让
- 距离 ≤ **1.5 米**（默认阈值）且置信度足够 → 发出近距离障碍物警告。
- 距离未知或置信度不足 → 只说"请注意周围环境"，不指挥具体避让动作。

### 准则 4：不轰炸用户
- 同一类别消息在 **3 秒内**重复出现 → 自动抑制，避免信息过载导致误判。

### 准则 5：设备永远是"辅助"，不是"决策者"
- 不替代盲杖、导盲犬、定向行走训练和个人判断。
- 不做过马路决策；遵守交通规则永远优先于设备提示。

## 设备绝不做的事

- 不承诺安全，不保证独立出行能力。
- 不录制、不保存视频、音频、位置信息。演示版仅在内存中保留最近 100 条引导事件的元数据（时间、类型、置信度），重启即清空。
- 不在未经验证的场景下更新引导规则；规则变更必须先通过可复现的 JSONL 回放测试。

## 与项目主线的关系

这是"让不确定性可见"在助盲硬件上的直接体现：
GERT 让电网模型的不确定性可见，EPSILON 让回测假设可见，
AI Glasses 让设备自身的"不知道"可见。

## 诚实声明

本设备为研究原型，**未经过临床验证、实地安全验证或任何认证**。
以上准则描述的是软件当前已实现的行为（见仓库 `aiglasses/` 与 `docs/ARCHITECTURE.md`），
不是对未来硬件版本的安全承诺。任何真实出行场景使用前，必须经过受控环境测试。
