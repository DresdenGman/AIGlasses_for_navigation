# 随访工具包 Packing List（寄 / 带清单）

> 原则：一次备齐，不二次补寄。数量按"应邀人数 N"计算，N 待定先按 8 人备。

## 打印品（黑白即可，字要大）

| 物品 | 数量 | 备注 |
|---|---|---|
| BOM 双语清单 | N + 2 | 给老人带回家的 |
| 组装步骤卡 | N + 2 | 给老人带回家的 |
| 常见故障一页纸 | N + 2 | 给老人带回家的 |
| 回访问卷 | N + 5 | 现场发，多的备用 |
| 签到表 | 2 张 | 每张 20 行 |
| 给对接人的信 | 1 份 | 一页纸：流程 + 时间 + 需要对方做的事 |
| 给老人的信（仅 C 方案） | N 份 | 一页纸：说明来意 + 回访时间 |

## 电子 / 其他

| 物品 | 数量 | 备注 |
|---|---|---|
| U 盘 | 1 个 | 含 5 分钟教学视频 + 工具包电子版（B 方案必需，A/C 可选） |
| 网盘链接 | 1 个 | 与 U 盘内容一致，双备份 |
| 回邮信封（仅 C 方案） | N 个 | 贴好邮票、写好地址；建议以电话代填为主 |
| 笔 | 5 支 | 现场问卷用 |

## 寄送要求

- 快递：顺丰，提前至少 5 天寄出。
- 寄出后把单号 + 物品清单拍照发给对接人，请对方清点。
- U 盘里的视频寄出前自己完整播一遍，确认能打开、有声音、有字幕。
