# Internal operational drafts

Working notes for community follow-up logistics: outreach messages, visit plans, a packing list, a questionnaire, a short video script, and an unfilled visit-report template. They are not setup instructions, not a product manual, and not evidence that a follow-up program was completed.

These drafts may include names, community contacts, or logistics that should not be copied into public claims, issues, or new documentation. Do not add filled-in names, recordings, returned questionnaires, or contact details to this folder.

Public project documentation stays in `docs/` outside this folder (build guide, safety note, demo, architecture). The OER submission note remains at [../OER_SUBMISSION_PACKAGE.md](../OER_SUBMISSION_PACKAGE.md) because it indexes that public build guide. The runnable demo does not depend on anything here.
