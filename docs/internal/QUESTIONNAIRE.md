# 回访问卷（草稿 v0.1，2026-09-25）

> 设计原则：匿名、自愿、不记名；问题短、字大，适合老人；**诚实反映现实**——有人不愿参加、有人记不住，都是正常数据，照实记录。
> 形式：纸质为主（字大），也可由志愿者代读代填。回收后脱敏汇总，原始问卷不公开。

**卷首语（印在问卷顶部）：**
> 这份问卷匿名、自愿填写，不记名字，不影响您参加任何活动。我们想了解上次的眼镜制作讲解对您有没有用、哪里不清楚，以便改进。谢谢您！

## 回收与记录规范

- 只记录：**发出 X 份、回收 X 份**；每题的选项分布如实统计。
- 开放题原话引用需经本人同意，匿名处理（如"某位 70 岁的参与者"）。
- **不计算"满意度百分比"**，不写"好评率"——样本小、自愿填写，算出来也没有意义，招生官看得出。
- 原始问卷由居委会对接人保管，不上传公开仓库；公开的只是脱敏汇总数字。
