# AI Glasses「最小闭环」回访方案

> 状态：草稿 v0.1，2026-09-25。Phase 0 交付物，待用户定稿。
> 目标：在 10 月底前完成一次有记录的跟进闭环，产出可写入申请活动列表的诚实数字。

## 约束

- 申请季：REA 11 月初 / RD 1 月初，不再参加任何竞赛。
- 现实：单社区完全符合条件的老人比例不高；部分视障人士不愿参加；产品服务特定群体。方案不回避这些事实。
- 地理：用户在美国，社区在中国 → 动作必须可远程完成，或有本地人落地。

## 目标

和 **1 个最配合的居委会**完成：教学跟进 → 回访 → 可量化证据。产出 3 个诚实数字。

## 五步走

### Step 1：选 1 个最配合的居委会（用户定）
标准：之前参与度最高、有愿意对接的工作人员、有 3–5 位明确表示愿意再参加的老人。

### Step 2：准备工具包（已起草，outbox/ 内）
BOM 双语清单、组装步骤卡、故障一页纸，提前发给对接人。

### Step 3：教学跟进（一次，60–90 分钟）
不从零教，而是"上次教的还记得多少 + 这次解决 1–2 个实际卡点"。

### Step 4：回访（1–2 周后，30 分钟）
- 请老人**独立复述 / 演示 2–3 个关键步骤**，记录：能独立完成 / 需提示 / 不能完成。
- 回收匿名问卷（见 QUESTIONNAIRE.md，自愿）。

### Step 5：证据整理（模板待做）
一页纸：实到人数、独立复述人数、问卷回收数、1–2 句老人原话（匿名、经同意）。

## 时间预算（用户总投入约 5–7 小时，分 4–6 周）

| 环节 | 时间 |
|---|---|
| 选社区 + 和对接人沟通 | 1–2 小时 |
| 审核工具包 | 1 小时 |
| 教学跟进 | 1.5–2 小时 |
| 回访 | 1 小时 |
| 审核证据一页纸 | 0.5 小时 |

## 地理方案三选一（待用户定）

- **A.** 用户远程视频连线主持，居委会对接人负责现场组织。
- **B.** 用户写脚本 + 录 5 分钟教学视频，本地人代主持，用户远程回访。
- **C.** 不做新活动，做"远程回访 + 工具包寄送"，证据为回访记录和签收。

## 证据指标（诚实版，申请用）

- 实到 X 人（应邀 Y 人，到场率照实写，备注"部分老人不愿参加"）。
- 能独立复述关键步骤 X 人。
- 回收匿名问卷 X 份。
- 一句话：跟进后某位老人能独立完成某个步骤（匿名、经同意）。

**不写**：不写"影响 60 人"，不写"部署 X 台"，不写"满意度 100%"。

## 时间线（对齐总计划）

- Phase 0（9/25–9/28）：本方案定稿，工具包 + Safety Note 上线。
- Phase 1（9/29–10/5）：视频脚本定稿、问卷定稿、联系居委会。
- Phase 2（10/6–10/19）：回访执行 + 问卷回收 + 脱敏报告上线。
- Phase 3（10/20–11/1）：证据汇总 + 活动列表 150 字符版。
