# Participant feedback data

Raw and derived data for the participant feedback survey reported in
[docs/FEEDBACK.md](../../docs/FEEDBACK.md).

| File | Contents |
|---|---|
| `participant-feedback-survey-responses-2026.csv` | Raw survey export as provided: 72 anonymous responses (36 Chinese, 36 English), 26 August – 4 November 2026. Contains no names, email addresses or contact fields. |
| `summary.json` | Every count published in the feedback report, generated by the script below. |
| `analyze_feedback.py` | Merges the bilingual Chinese/English column blocks and regenerates `summary.json`. Standard library only: `python3 analyze_feedback.py` |
| `make_charts.py` | Renders the four charts in `assets/feedback/` from `summary.json` (requires matplotlib). |

Quotations from open-ended answers are published in the report only for
respondents who agreed to anonymous quotation (57 of 72).
